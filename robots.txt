# Content Signals state how this content may be used, rather than leaving each
# crawler to infer it. See https://contentsignals.org for the specification.
#   search   = building a search index and returning links/short excerpts
#   ai-input = using the content to ground a generated answer (RAG)
#   ai-train = training or fine-tuning a model

# invites the training crawlers by name (CCBot, Google-Extended,
# Applebot-Extended). Note this is the opposite of canonical.cc's stance, which
# sets ai-train=no. Flip this line to `no` and drop those three from the
# allow-list if the two sites should agree.
