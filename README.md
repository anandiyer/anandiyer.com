# anandiyer.com

Personal site for Anand Iyer. Plain HTML + CSS + a tiny vanilla-JS island that
hydrates the four content rails from `/data/*.json`. No build step, no framework.

## Stack
- GitHub Pages (`master` branch, served from repo root)
- `CNAME` → `anandiyer.com`
- Aesthetic: Collison-style — serif (Charter), off-white background, single column

## Local preview
```sh
cd anand-site
python3 -m http.server 8080
# open http://localhost:8080
```
(Use a real server, not `file://`, so `fetch('/data/...')` works.)

## Editing content
All editable copy lives in two places:

| What           | Where                       | Refresh                          |
|----------------|------------------------------|----------------------------------|
| Bio / sections | `index.html` (prose inline)  | manual                           |
| Investments    | `data/investments.json`      | manual                           |
| Writing        | `data/writing.json`          | manual                           |
| Talks & press  | `data/talks.json`            | manual                           |
| Tweets         | `data/tweets.json`           | **auto, hourly** (see below)     |

### Tweet rail (live)
`data/tweets.json` is regenerated by `.github/workflows/refresh-tweets.yml`
every hour. The workflow runs `scripts/fetch-tweets.py`, which calls
`syndication.twitter.com` (the public endpoint Twitter's own embed widget uses
— no API key) and writes the latest 12 originals from `@ai`. It commits only
when the JSON changed, keeping git history clean.

Manual refresh: `python3 scripts/fetch-tweets.py --handle ai --limit 12`.

## Deploy
Push to `master`. GitHub Pages auto-serves. Cache-bust CSS/JS via `?v=YYYYMMDDx` if needed.
